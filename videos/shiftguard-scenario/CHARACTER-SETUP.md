## 零、先講一個你要自己決定的取捨

你在招商片的 BRIEF 裡訂了一條硬規則：**「不要 emoji 與卡通插畫」**。
改成日系動畫風，表面上會踩到這條。

我的判斷是**可以做，但要選對路子**。那條規則真正要擋的是
「可愛化、扁平向量插畫、吉祥物賣萌」那種降低嚴肅度的東西。
而**劇場版動畫的寫實日常系**是另一個東西——《言葉之庭》那種質感，
它處理的是安靜、疲憊、光線與情緒，嚴肅程度不輸實拍。

改動畫風反而解掉三個問題：

1. **恐怖谷消失**——AI 生的真人臉在醫療場景裡最容易出戲，動畫沒這問題
2. **一致性大幅變好**——動畫風對細微差異的容忍度遠高於寫實人像
3. **倫理風險降低**——沒有人會把動畫護理長誤認成真實見證，你的「不要假見證」原則更穩

但代價要認：**如果這支片要剪進招商片**，動畫段落和現有的幾何字卡並存，
風格必須靠色票統一（下面第二節處理了這件事）。

**紅線不變**：不出現病人、不出現醫院名稱與 logo、識別證留白。

## 一、風格定義（所有提示詞的共同基準）

### 要的
- **劇場版動畫的寫實日常系**：手繪背景美術 ＋ 賽璐璐上色人物
- **光是主角**：日光燈的冷白、玻璃與檯面的反射、走廊深處的暗、黎明的漸層
- **寫實人物比例**：成熟女性的臉型與身形，線條收斂
- 低飽和冷色調，輕微紙張顆粒感
- 背景資訊密度高（堆疊的病歷夾、白板的塗改痕跡）——日常系的說服力來自細節

### 不要的（每則提示詞都會寫進去）
- 萌系、大眼睛、Q 版、chibi
- 粉彩色、閃亮特效、花瓣飄落
- 輕小說插畫風、同人風、賽璐璐廣告風
- 誇張表情、汗滴符號、情緒符號

### 色票（跟平台同一套，剪在一起才不打架）
| 用途 | 色碼 | 在畫面裡是什麼 |
|---|---|---|
| 暗場底 | `#101b30` | 走廊深處、夜晚的窗外 |
| 冷白光 | `#f3f5fa` | 日光燈管、螢幕光 |
| 主色 | `#4060ef` | 收尾轉場、字卡 |
| 墨色 | `#16233a` | 線條與陰影 |

產圖時可以直接把色碼寫進提示詞（下面的提示詞已經寫好了）。

## 二、人物設定表（鎖定，之後所有提示詞都以此為準）

### 基本
| 項目 | 設定 | 備註 |
|---|---|---|
| 內部代號 | 護理長 H | **畫面上永不出現姓名** |
| 年齡 | 42 歲 | 動畫裡要畫得出這個年紀，不是 20 代 |
| 職務 | 內科病房 3A 護理長 | 對應平台示範單位 MED-3A |
| 年資 | 19 年，其中 6 年帶病房 | 影響體態與眼神：不慌，但很累 |

### 外形（硬鎖，每張圖都要一致）
- 中等身高、偏瘦，**肩膀微微內收**（長期疲勞的體態，不是挺拔站姿）
- 黑色及肩頭髮，腦後綁成低髮髻，鬢角有幾根散落的碎髮
- **細金屬框眼鏡**（不是粗黑框、不是無框、不是圓框）
- 眼型偏細長，**不是動畫常見的大圓眼**；眼下有淡淡陰影
- 法令紋、眼角細紋要畫出來——這是她 42 歲的證據
- 深藍色刷手服，外面罩一件米白色薄外套
- 識別證掛繩：純色，**證件正面完全空白**
- 沒有耳環項鍊，左手一支舊的金屬錶帶手錶

### 氣質（決定表情集怎麼畫）
- **她的疲憊是安靜的**——不哭、不崩潰、不誇張嘆氣
- 動作慢半拍，下決定前會停頓
- 看班表時是「在算」，不是在發呆
- 情緒往內收

### 隨身道具（每一鏡都要在，建立連貫感）
- 紙本班表一疊，有鉛筆塗改痕跡
- **不鏽鋼保溫杯**（不要咖啡紙杯——台灣護理站幾乎都用保溫杯）
- 桌上有線電話
- 白板加磁鐵
- 手機（影片裡螢幕永遠失焦）

## 三、台灣病房的六個關鍵細節（AI 最常搞錯）

沒指定的話，AI 會生出日本醫院或美劇醫院。動畫風尤其容易滑向日本場景：

1. **護理站檯面是米色或淺木紋美耐板**，不是深色實木
2. **天花板是冷白色日光燈管**，不是暖色嵌燈
3. **牆上是手寫白板**在排班，不是電子看板
4. **地板是塑膠地磚**，有磨損接縫
5. **走廊窄**，兩側牆上有扶手
6. **檯面上堆紙本病歷夾**，不是整齊的平板

```
角色：一位 42 歲的台灣女性護理長。
```

### 設定圖 B — 表情集（表情集）

> 生完 A 之後，**在同一個對話裡**接著貼：

```
同一個角色，請再生一張表情集（expression sheet），橫式，白色底，

1. 平靜疲憊——看著班表時的預設表情
```

## 五、驗收清單（每張逐項 check，不過就重生）

**人物**
- [ ] 看起來確實是 42 歲，不是 20 代
- [ ] 眼型偏細長，**不是大圓眼**
- [ ] 眼鏡是細金屬框
- [ ] 有畫出法令紋／眼角細紋
- [ ] 肩膀微微內收，不是挺拔站姿
- [ ] 識別證空白，沒有偽造文字
- [ ] 表情克制，沒有動畫式誇張或情緒符號

**風格**
- [ ] 是劇場版寫實日常系，不是萌系／輕小說插畫風
- [ ] 低飽和冷色調，沒有跑出粉彩
- [ ] 有手繪背景質感，不是扁平向量

**場景**
- [ ] 檯面是米色美耐板，不是深色木頭
- [ ] 冷白日光燈管
- [ ] 手寫白板，不是電子看板
- [ ] 塑膠地磚、窄走廊有扶手

**紅線**
- [ ] 沒有病人、沒有其他人入鏡
- [ ] 沒有任何可辨識文字（AI 生的中日文幾乎都是亂碼）
- [ ] 沒有醫院名稱或 logo

## 六、生歪了怎麼修（直接貼這些話）

| 問題 | 對 ChatGPT 說 |
|---|---|
| 畫成萌系大眼 | 「眼睛太大太圓了，變成萌系了。請重生：眼型改成偏細長的寫實比例，畫出法令紋和眼角細紋，讓她確實看起來是 42 歲的成熟女性。風格要劇場版動畫的寫實日常系，不是輕小說插畫。」 |
| 太年輕 | 「她看起來像 20 幾歲。請重生成 42 歲：臉型更成熟、有細紋、眼下有陰影、肩膀微微內收，是上了一整晚班的體態。」 |
| 變成日本醫院 | 「場景太像日本醫院了。請改成台灣醫院：米色美耐板檯面、冷白日光燈管、牆上是手寫白板、地板是有磨損的塑膠地磚、走廊窄且兩側有扶手。」 |
| 出現亂碼文字 | 「畫面出現了文字。請重生並確保：白板和紙張上的字跡完全模糊不可辨識，識別證正面完全空白，畫面中沒有任何招牌或標示。」 |
| 顏色太鮮豔 | 「色彩太飽和了。請改成低飽和的冷色調，以深藍 #16233a 作線條與陰影、走廊深處沉入 #101b30，整體像深夜的日光燈下。」 |
| 第二張換了人 | 把 A 圖重新上傳，說：「以我上傳的這張設定圖的臉為準，同一個角色，請畫表情集。臉、髮型、眼鏡、衣服都不要變。」 |
