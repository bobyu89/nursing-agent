# 班守導入路線圖 — ChatGPT 產圖提示詞

> 老師的「一年導入戰略圖」骨架收下，內容換成班守的：
> 四方責任（護理部／資訊室／人資／導入方）、按風險排序的三段上線（收集與建議→平行對照→寫回）、
> 驗收指標寫在第一個月。畫出來的圖進 BLUEPRINT.md 當「怎麼導入」的正式答案。
>
> **怎麼用**：把第一節整段貼進 ChatGPT。小字亂碼就改用第二節的「分兩張」，
> 還是亂碼就用第三節的「叫它寫程式畫」——文字百分之百正確，版面稍陽春。

---

## 一、完整提示詞（一次生一張，先試這個）

```

不要自行增刪、改寫或翻譯任何字。全部使用繁體中文，不可以出現簡體字。

【視覺風格】
極簡、大量留白、細線、無漸層、無陰影、無圖示、無插畫。
底色 #f3f5fa（近白的冷灰）。主色 #4060ef（靛藍），用在曲線、里程碑節點、

【版面：由上到下三個區塊】

主標題下方畫一條由左下往右上緩緩爬升的平滑 S 型曲線，靛藍色細線。
曲線上依序放六個節點（小圓點＋垂直短線＋文字），文字排在節點上方：

M1｜規則與驗收定案
護理部核定規則庫、人資核定法規門檻

M6｜平行排班完成
跨兩個 28 天週期，違規數對照

M7｜驗收決策
修正、停止或上線

M12｜營運交接
規則維護與監控由院方接手

三個等高的橫向色塊並排，由左到右顏色由淺到深（#edf1fe → 中間靛藍 → 深靛藍 #4060ef），

第一段｜收集與建議｜M3
換班預檢、替補建議、線上預假——不改任何班表

第二段｜平行對照｜M4–M7
預班草稿「暫緩」保留，與人工班表對照違規數——用同一批預假

第三段｜寫回｜M8–M12
預班核准並公告、替班逐一詢問——分批病房，3A 先行

── 區塊 3：四方責任矩陣（佔下方 45%）──

小標：四方關鍵執行動作
一張 5 列 × 6 欄的表格。第一列是表頭（深色底 #16233a、白字），第一欄是角色名稱
（淺靛藍底 #edf1fe）。格內文字用小字、每格兩行。

【再次強調】
```

## 二、亂碼就切兩張（各貼一次，同一個對話裡）

**上半張**：把第一節裡「視覺風格」＋「區塊 1」＋「區塊 2」貼進去，
最後加一句：`這張只畫區塊 1 和區塊 2，版面改成 16:9 橫式，區塊 1 佔 65%、區塊 2 佔 35%。`

**下半張**：把「視覺風格」＋「區塊 3」＋「驗收指標框」＋「頁尾」貼進去，
最後加一句：`這張只畫區塊 3、驗收指標框和頁尾，16:9 橫式，矩陣佔 75%、指標框在右側佔 25%。`

兩張的底色與色票相同，之後在簡報裡上下疊就是一張完整的圖。

## 三、還是亂碼：叫它用程式畫（文字百分之百正確）

把第一節整段貼進去，但把開頭第一句換成：

```
請用 Python（matplotlib，中文字型用 Noto Sans CJK TC 或系統可用的繁體中文字型）
把以下規格畫成一張 1920×1080 的 PNG 資訊圖，直接執行程式並讓我下載圖檔。
版面、文字、色碼都嚴格照規格，不要簡化內容。
```

ChatGPT 會用 Code Interpreter 跑程式，文字一定正確，版面比較工整但少了設計感。
拿到之後如果你想要更好看的版本，把這張 PNG 上傳回去說「照這張的版面重畫一張設計感更強的」，
成功率會比一開始就畫高很多——因為它已經看到正確的排版了。

## 四、驗收（畫出來之後逐項對）

- [ ] 六個里程碑的月份與文字正確（M1／M2／M3／M6／M7／M12）
- [ ] 風險三段順序正確：收集與建議 → 平行對照 → 寫回
- [ ] 矩陣是四個角色（護理部、資訊室、人資、導入方），不是三個
- [ ] 驗收指標四條都在，且標明「M1 定案」
- [ ] 沒有簡體字、沒有亂碼、沒有它自己加的英文
- [ ] 色系是靛藍不是綠色（跟老師的圖區分開，也跟你的平台一致）

## 五、這張圖跟老師那張的差異（評審問時的答案）

| 老師的模板 | 班守的版本 | 為什麼 |
|---|---|---|
| M1–M4 準備、建原型 | M1–M2 就緒，M3 唯讀上線 | 規則引擎已存在、155 項測試在跑、兩條 LINE 迴路已上線，不需要建原型，省下的時間給平行驗證 |
| 「限定試行」一段 | 收集與建議 → 平行對照 → 寫回三段 | 按風險排序：預檢、建議與預假收集不改班表，護理長第一天就能用 |
| 三方（管理／第一線／導入） | 四方（護理部／資訊室／人資／導入） | 護理部管規則、資訊室管資安介接、人資管勞基法門檻——三者權責不同，混在一起會沒人簽字 |
| M9 才「依成效決定」 | M1 就定驗收指標 | 違規條數可客觀對照，不然驗收會變成「感覺還可以」 |
| 沒有勞務法遵角色 | 人資獨立一列 | H4–H10 的解釋權在人資；三班護病比入法後護理排班是勞檢重點 |
