班守 ShiftGuard

缺工情境下的排班與人力缺口決策支援工具。
在醫護人力短缺、無法即時增加人力的現實裡， 把缺工從模糊感受變成可量化、可追蹤、可行動的管理資訊。

它不承諾解決缺工——它承諾讓每一個缺口被更早看見、被誠實計算。

進入平台 → 加入 LINE 通報機器人

三件事，缺一不可

只做「快」的話，Excel 篩選就夠了。平台存在的理由是後面兩件事。

算得準

工時、班距、連續天數、證照效期——全部由確定性規則引擎計算，45 項邊界測試釘住。語言模型不碰任何數字：算錯工時在醫療場域是合規事故，不是體驗瑕疵。

說得清

每一位候選人的分數攤得開、每一筆排除都寫明規則代碼與原因。「為什麼找他不找我」從此有答案——這是護理職場公平的起點。

留得下

每一步決策寫入雜湊鏈結的留痕，改任何一筆都會被抓到。勞檢、稽核、評鑑，一鍵匯出舉證。

功能總覽

進入平台後以四個分頁組織：總覽 ・ 缺班處理 ・ 排班 ・ 治理

◎人力缺口儀表板

缺口方程式：營運所需 − 已排定 ＝ 缺口 → 合法吸收模擬（含代價）→ 誠實殘餘。結構性缺口自動判定，直接變成員額與預算的證據。

★能力徽章與帶班平衡

資格徽章（含效期）答「有沒有人會做」；進階徽章 N1–N4／AHN 答「有沒有人扛得住」。三班帶班平衡熱圖讓「夜班全是新人」無所遁形。

1缺班替補（第 1–2 層）

貼上請假訊息 → 解析追問 → 合格候選排序與評分卡 → 主管確認留痕。找不到人時：放寬試算與多筆全局指派，只試算、不自行放寬。

7韌性模式（第 3 層）

連替補都無解時，缺的不再是「一個人」，是「一班的任務」——任務重分配：資格硬性匹配、負荷平衡，補不上的誠實標示為缺口。

8班表生成（第 0 層）

用與替補完全相同的一份規則生成下週班表——排出來的那一刻就合規；生成後疊回現有班表重掃驗證，零新增風險。

LLINE 通報機器人

通報入口放在護理師本來就在用的 LINE：訊息解析、按鈕補條件、替補建議、詢問草稿、戰情儀表板——同一份引擎，零學習成本。

決策階梯：從源頭治理到韌性降級

上層做得越好，下層被觸發得越少——我們的成功指標是韌性模式的啟動次數逐季下降。

第 0 層　班表生成——排出來的那一刻就合規
第 1 層　找合格替補——硬性排除、軟性排序、逐筆交代
第 2 層　放寬試算＋全局指派——把選項與代價攤開，決定權在主管
第 3 層　任務重新分配——極端情境下的降級運作方案，缺口誠實攤開
誠實聲明：本站為教學展示——所有人員、班表、請假資料皆為虛構（代號 N-01～N-11）， 不含任何病患資料；訊息解析為確定性關鍵詞規則（非真實模型），理解力有限但離線可跑、可驗證； Agent 不臆測缺漏欄位、不自行放寬規則、不代替主管決定，通知一律停在草稿。
